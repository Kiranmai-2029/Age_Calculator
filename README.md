# Age_Calculator
🎂 Age Calculator
📌 About

Age Calculator is a simple and user-friendly application that calculates a person's exact age based on their date of birth.

✨ Features
Calculate age in years, months, and days.
Simple and attractive user interface.
Fast and accurate calculations.
Easy to use.
Responsive design.
🛠️ Technologies Used
HTML
CSS
JavaScript
🚀 How to Run
Clone this repository:
bash
git clone YOUR_REPOSITORY_URL

Open the project folder.
Open index.html in your browser.
